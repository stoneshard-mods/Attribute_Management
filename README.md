# Attribute_Management

属性 / 技能点退还 Mod（作者：Pixel32E）

## 功能简介
- **属性点退还**：当属性值高于职业初始值时，属性行右侧（「+」左侧）出现「−」按钮，点击退还 1 点（属性 −1，可用属性点 +1）。
- **退点保护**：若退点会导致已学技能不满足属性需求，则阻止退点并弹出提示。
- **技能点退还**：在技能树中右键已学技能图标，退还 1 点技能点。
- **前置依赖**：有后续技能依赖时不可先退前置，需从最外层向内逐级退还；退点后不满足前置的后续技能自动重新锁定，重学后自动恢复。
- **基础技能锁定**：屠宰 / 制作 / 搜寻陷阱 / 火炬攻击 / 突袭 不可退还。
- **视觉反馈**：退点时技能树连线播放反向动画。
- **多语言**：EN / 中文 / Русский / 日本語 / 한국어（游戏内 ESC → 设置 → MODS → Attribute_Management → Language 切换）。

## 项目结构
- `Attribute_Management.cs`：Mod 主逻辑
- `Gml/`：游戏脚本
- `Textures/`：图标与贴图资源
- `icon.png`：Mod 图标

## 构建
使用 ModShardLauncher 编译为 `Attribute_Management.sml` 后放入 Mods 目录加载。
